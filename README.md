# 📸 User Image Gallery — Java Backend with Pure HTML Frontend
This project is a full-stack web application for managing user-specific image galleries, combining a Java backend with a pure HTML frontend. Each user can create albums, upload images, and browse their personalized gallery via a clean and responsive interface.

## 🌐 Project Overview
The application allows multiple users to create and manage their own photo albums. The backend, developed in Java, handles user authentication, image storage, and album organization, while the frontend presents the data using lightweight HTML pages.

## ✨ Key Features
- 👤 User Management: Secure login and registration system for users.
- 📁 Album Creation: Users can create, rename, and delete albums.
- 🖼️ Image Uploading: Users can upload images to specific albums.
- 🔍 Gallery View: Each album is presented as a responsive image grid.
- 🌐 Pure HTML Frontend: All views are rendered using clean, static-like HTML with backend support for dynamic content.

🛠️ Technical Stack
- Frontend: Pure HTML (with CSS for styling)
- Backend: Java
